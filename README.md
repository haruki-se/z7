# G3 INPUT CHECK

ZOOM G3のUSB音声入力を確認する、依存パッケージ不要のWebアプリです。

## 起動

```sh
cd /workspace/z7
python3 -m http.server 8000 --bind 127.0.0.1
```

**G3を接続したPC**でファイルを配置し、同様にHTTPサーバーを起動して `http://localhost:8000` を開いてください。Python 3が必要です。クラウド上のブラウザから手元PCのUSBデバイスにはアクセスできません。遠隔配信する場合はHTTPSが必要です。

1. G3をUSB接続し、ギターとスピーカー（またはヘッドホン）を接続します。
2. 「入力を開始」でマイク使用を許可します。
3. 既定の入力がG3でなければ「停止」してG3の入力を選び、再度開始します。
4. 「スピーカー出力をオン」を押し、出力音量を調整します。初期音量は20%です。OSのサウンド設定で出力先を選択してください。
5. ギターを弾き、リアルタイムの音・レベル・波形を確認します。「10秒録音」で録音し、停止後に再生または保存できます。

表示値はRMSのdBFSです。ピークが0.98以上で警告します。ブラウザの解析はモノラルにまとめた信号のため、左右チャンネル別の診断には対応しません。音声はサーバーへ送信しません。ライブ出力は初期状態でオフになり、入力停止時にもオフに戻ります。録音の再生を始めるとライブ出力は自動でオフになります。録音形式はブラウザによって異なります。

## リアルタイム出力について

低遅延設定で入力をOSの既定の出力へ再生します。ブラウザ・ドライバー・機器による遅延は残ります。Bluetoothより有線接続がおすすめです。入力はG3を選んでください。内蔵マイクをスピーカーへ出力するとハウリングすることがあります。G3のダイレクトモニターと二重に聞こえる場合はブラウザ出力をオフにしてください。

## 検証

`node --check app.js` で構文を確認できます。音声入力と録音の実機確認には、G3を接続したPCとマイク権限が必要です。無音、信号検出、過大入力の警告、録音・再生・保存、停止後のマイク解放を確認してください。
